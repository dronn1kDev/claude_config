# Первоначальная настройка Claude Code для claude_config

Репозиторий подключается к Claude Code как локальный маркетплейс `dronn1k-kit`: плагины читаются прямо из клона, а правки подхватываются командой `/reload-plugins`. Ниже `$REPO` — абсолютный путь к вашему клону; в командах Claude Code (`/plugin`, `/config`) подставьте его вручную. Установка для других пользователей описана в [README.md](README.md).

## Шаги

1. **Добавить маркетплейс** — в Claude Code:

   ```
   /plugin marketplace add $REPO
   ```

2. **Установить плагины:**

   ```
   /plugin install dk-research@dronn1k-kit
   /plugin install dk-code@dronn1k-kit
   /plugin install dk-notes@dronn1k-kit
   /plugin install dk-report@dronn1k-kit
   ```

3. **Задать папку исследований:** `/config` → `dk-research` → `research_dir = $REPO/research`. Папка в `.gitignore`, заметки остаются локальными, а Obsidian видит их в этом же vault.

4. **Убрать старые симлинки**, если настройка делалась раньше через них. Если `~/.claude/CLAUDE.md` — симлинк на репозиторий, замените его обычным файлом: в репозитории `CLAUDE.md` больше нет. Чтобы протокол `engineer` работал на каждой задаче с кодом, добавьте в `~/.claude/CLAUDE.md` указатели на скиллы (пример в [README](README.md)).

   ```bash
   for item in agents skills hooks commands claude_config CLAUDE.md; do [ -L ~/.claude/$item ] && rm ~/.claude/$item; done
   ```

5. **Перезапустить сессию** или выполнить `/reload-plugins`.

6. **Подключить коннекторы (по желанию).** Агент `dk-research:analyst` умеет искать через Notion, Gmail и Atlassian; без них — только веб и код.

Личные настройки — локальные пути, ссылки на свои базы и т. п. — кладите в `local/`: папка в `.gitignore`. Репозиторий можно открыть в Obsidian как vault: `.obsidian/` тоже в `.gitignore`.

## Как проверить

- `/plugin` — маркетплейс `dronn1k-kit` и четыре установленных плагина.
- `/agents` — `dk-code:engineer`, `dk-code:architect`, `dk-research:analyst`.
- `/memory` — user memory `~/.claude/CLAUDE.md`.
- Первый запуск любого скилла спрашивает язык; после ответа появляется `~/.config/dronn1k-kit/language`.

## Локальная разработка

Правки в `plugins/` подхватываются командой `/reload-plugins`, без переустановки. Перед коммитом проверьте маркетплейс и плагины:

```bash
claude plugin validate "$REPO"
for p in "$REPO"/plugins/dk-*; do claude plugin validate "$p"; done
```

Предупреждения о `version` ожидаемы: версия не задана намеренно, чтобы обновления приходили с каждым коммитом.

## Если не получилось

| Симптом | Причина | Что сделать |
|---|---|---|
| Агентов или скиллов нет в `/agents` и `/plugin` | Плагины не установлены или сессия не перезапущена | Шаги 2 и 5 |
| Агенты видны дважды: с префиксом и без | Остались старые симлинки `~/.claude/agents` или `~/.claude/skills` | Шаг 4 |
| `analyze` сохраняет не в `research/` репозитория | Не задана опция `research_dir` | Шаг 3 |
| Правки в `plugins/` не действуют | Плагины не перечитаны | `/reload-plugins` |
