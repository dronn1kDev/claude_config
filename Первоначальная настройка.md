# Первоначальная настройка Claude Code для claude_config

Конфиг подключается к Claude Code симлинками из `~/.claude` на папки репозитория, так что правки в репозитории сразу действуют во всех сессиях. Ниже `$REPO` — абсолютный путь к вашему клону:

```bash
export REPO=/path/to/claude_config
```

## Шаги

1. **Заменить путь к репозиторию на свой.** В [CLAUDE.md](CLAUDE.md), [agents/engineer.md](agents/engineer.md) и [skills/analyze/SKILL.md](skills/analyze/SKILL.md) прописан абсолютный путь к репозиторию на машине автора (`/Users/<имя>/claude_config`). По нему `engineer` находит правила кода, а `analyze` — папку `research/`.

   ```bash
   grep -rlE "/Users/[^/]+/claude_config" "$REPO/CLAUDE.md" "$REPO/agents" "$REPO/skills" | xargs sed -i '' -E "s|/Users/[^/]+/claude_config|$REPO|g"
   ```

   В Linux вместо `sed -i ''` — `sed -i`. Если отправляете правки автору, эту замену в них не включайте.

2. **Создать папки, которых нет в git:** `commands/` пустая, `research/` в `.gitignore`.

   ```bash
   mkdir -p "$REPO/commands" "$REPO/research"
   ```

3. **Создать симлинки.** Если в `~/.claude` уже есть настоящие (не симлинки) `CLAUDE.md`, `agents`, `skills`, `commands` или `hooks`, сначала перенесите их, иначе `ln` положит ссылку внутрь папки.

   ```bash
   for item in CLAUDE.md agents skills commands hooks; do ln -sfn "$REPO/$item" ~/.claude/$item; done
   ```

4. **Подключить хук (по желанию).** `hooks/analyze-trigger.py` на `UserPromptSubmit` напоминает Claude про скилл `analyze`, когда в сообщении есть «проанализируй», «исследуй», «research» и т. п. Без него скилл тоже срабатывает по инструкции из `CLAUDE.md`, хук делает это надёжнее. В `~/.claude/settings.json`:

   ```json
   {
     "hooks": {
       "UserPromptSubmit": [
         {
           "hooks": [
             { "type": "command", "command": "python3 ~/.claude/hooks/analyze-trigger.py" }
           ]
         }
       ]
     }
   }
   ```

5. **Подключить коннекторы (по желанию).** Агент `analyst` умеет искать через Notion, Gmail и Atlassian; без них — только веб и код.

   > [!warning]
   > Скилл `timetrack` пишет в конкретную базу Notion автора и без правок у вас работать не будет. Не нужен — удалите `skills/timetrack`.

Репозиторий можно открыть в Obsidian как vault: `.obsidian/` в `.gitignore`.

## Как проверить

```bash
ls -la ~/.claude | grep "$REPO"
```

Пять ссылок: `CLAUDE.md`, `agents`, `skills`, `commands`, `hooks`.

```bash
grep -rE "/Users/[^/]+/claude_config" "$REPO/CLAUDE.md" "$REPO/agents" "$REPO/skills" | grep -v "$REPO"
```

Пустой вывод — путь автора нигде не остался.

```bash
echo '{"prompt":"проанализируй рынок"}' | python3 ~/.claude/hooks/analyze-trigger.py
```

JSON с `additionalContext`; для `"запусти flutter analyze"` — пустой вывод.

В новой сессии Claude Code: `/agents` показывает `analyst`, `architect`, `engineer`; `/memory` — user memory `~/.claude/CLAUDE.md`.

## Если не получилось

| Симптом | Причина | Что сделать |
|---|---|---|
| Агенты или скиллы не видны | `~/.claude/agents` осталась настоящей папкой, ссылка легла внутрь | Перенести папку, повторить шаг 3 |
| `engineer` не находит правила, `analyze` не сохраняет результат | В файлах остался путь автора или нет `research/` | Шаги 1 и 2 |
| Хук молчит | Нет ключа `hooks` в `settings.json` или `python3` не в `PATH` | Шаг 4 |
