# Первоначальная настройка Claude Code для claude_config

Конфиг подключается к Claude Code симлинками из `~/.claude` на репозиторий, так что правки в репозитории сразу действуют во всех сессиях. Ниже `$REPO` — абсолютный путь к вашему клону:

```bash
export REPO=/path/to/claude_config
```

## Шаги

1. **Создать папки, которых нет в git:** `commands/` пустая, `research/` и `local/` в `.gitignore`.

   ```bash
   mkdir -p "$REPO/commands" "$REPO/research" "$REPO/local"
   ```

2. **Создать симлинки.** Если в `~/.claude` уже есть настоящие (не симлинки) `CLAUDE.md`, `agents`, `skills`, `commands` или `hooks`, сначала перенесите их, иначе `ln` положит ссылку внутрь папки.

   ```bash
   for item in CLAUDE.md agents skills commands hooks; do ln -sfn "$REPO/$item" ~/.claude/$item; done
   ln -sfn "$REPO" ~/.claude/claude_config
   ```

   `~/.claude/claude_config` — ссылка на весь репозиторий. Через неё промпты находят то, что не подключается к Claude Code напрямую: `engineer` — правила кода в `rules/`, `analyze` — папку `research/`.

3. **Подключить хук (по желанию).** `hooks/analyze-trigger.py` на `UserPromptSubmit` напоминает Claude про скилл `analyze`, когда в сообщении есть «проанализируй», «исследуй», «research» и т. п. Без него скилл тоже срабатывает по инструкции из `CLAUDE.md`, хук делает это надёжнее. В `~/.claude/settings.json`:

   ```json
   {
     "hooks": {
       "UserPromptSubmit": [
         {
           "hooks": [
             { "type": "command", "command": "python3 ~/.claude/hooks/analyze-trigger.py" }
           ]
         }
       ]
     }
   }
   ```

4. **Подключить коннекторы (по желанию).** Агент `analyst` умеет искать через Notion, Gmail и Atlassian; без них — только веб и код.

Личные настройки — локальные пути, ссылки на свои базы и т. п. — кладите в `local/`: папка в `.gitignore`. Репозиторий можно открыть в Obsidian как vault: `.obsidian/` тоже в `.gitignore`.

## Как проверить

```bash
ls -la ~/.claude | grep "$REPO"
```

Шесть ссылок: `CLAUDE.md`, `agents`, `skills`, `commands`, `hooks`, `claude_config`.

```bash
echo '{"prompt":"проанализируй рынок"}' | python3 ~/.claude/hooks/analyze-trigger.py
```

JSON с `additionalContext`; для `"запусти flutter analyze"` — пустой вывод.

В новой сессии Claude Code: `/agents` показывает `analyst`, `architect`, `engineer`; `/memory` — user memory `~/.claude/CLAUDE.md`.

## Если не получилось

| Симптом | Причина | Что сделать |
|---|---|---|
| Агенты или скиллы не видны | `~/.claude/agents` осталась настоящей папкой, ссылка легла внутрь | Перенести папку, повторить шаг 2 |
| `engineer` не находит правила, `analyze` не сохраняет результат | Нет ссылки `~/.claude/claude_config` или папки `research/` | Шаги 1 и 2 |
| Хук молчит | Нет ключа `hooks` в `settings.json` или `python3` не в `PATH` | Шаг 3 |
