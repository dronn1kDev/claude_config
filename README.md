# Claude config

Этот vault подключён к Claude Code через симлинки из `~/.claude`. Настройка на новой машине — [Первоначальная настройка](Первоначальная%20настройка.md).

- `skills/<имя>/SKILL.md` — скиллы (фронтматтер: `name`, `description`)
- `agents/<имя>.md` — сабагенты
- `commands/<имя>.md` — слэш-команды
- `rules/` — правила написания кода для агента `engineer`: `general.md` для любого языка, `<язык>.md` для конкретного
- `hooks/` — скрипты хуков (подключаются в `~/.claude/settings.json`, он в vault не хранится)
- `research/` — сохранённые результаты аналитика (в .gitignore)
- `local/` — личные настройки: локальные пути, ссылки на свои базы и т. п. (в .gitignore)
- `CLAUDE.md` — глобальные инструкции для всех проектов

Ссылки внутри скиллов делать относительными путями, а не [[wiki-links]]. На файлы репозитория, которые не подключены к Claude Code напрямую (`rules/`, `research/`, `local/`), ссылаться через `~/.claude/claude_config/…` — это симлинк на репозиторий. Личные данные в отслеживаемые файлы не класть, только в `local/`.
